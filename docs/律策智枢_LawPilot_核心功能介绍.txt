一、登录与账号体系
--------------------------------------------------------------------------------
系统实行账号化管理，未登录用户无法访问任何页面，访问会自动跳回登录页。

1. 用户登录与注册
   · 登录：输入用户名 + 密码即可登录，支持「记住密码」（刷新页面自动回填）；
     登录采用 Token 校验，24 小时滑动续期，刷新页面自动保持登录态。
   · 注册：测试阶段开放注册，用户名 + 密码即可创建账号，注册成功自动登录；
     对用户名重名、非法格式（数字开头、位数不足）、密码过短（少于 6 位）均
     给出校验提示。
   · 退出登录：顶栏账号菜单一键退出；再次登录后会话、收藏、资料自动恢复。

2. 法律协议确认
   登录成功后弹出协议确认框（《用户协议》《隐私政策》《AI 咨询非正式法律
   意见声明》，均可点击查看全文），须勾选同意后「同意并继续」按钮方可点击，
   进入三栏式主界面。

3. 多用户数据隔离
   每个账号的会话、收藏、个人资料均存于服务端并按账号严格隔离：不同账号
   互不可见对方历史；登录自动拉取恢复数据，换设备或清除浏览器缓存后重新
   登录即可找回；修改密码需旧密码校验，成功后自动吊销其他设备的登录 Token。

二、法律问答与可信评估界面
--------------------------------------------------------------------------------
法律咨询问答是系统的核心功能，回答过程与结果均以可视化方式呈现。

1. 结构化法律回答
   · 三段式展示：法律类回答按【结论】—【法律分析】—【依据法条】固定结构
     输出，法条引用中的法律名称与条号高亮显示，一目了然。
   · 流式输出：采用 SSE 逐字输出（打字机效果），回答完成后气泡左下角显示
     模型角标；引用核验与完整可信评分在后台异步执行，经 WebSocket 推送
     动态更新，核验期间显示「引用核验中…」。
   · 多轮对话：追问自动携带上下文，回答连贯；会话首条法律问题发出后系统
     还会自动命名会话。
   · 智能体能力：触发工具调用时回答上方显示状态行（「正在检索法条…」→
     「命中 N 条法条」）；时效类问题（如「婚姻法还有效吗？」）直查法律时效
     注册表，给出确定性结论并标注来源。

2. 右侧分析详情面板（四 Tab）
   法律类回答完成后，右侧自动展示该回答的分析详情，点击任意回答气泡可
   切换查看。面板包含四个标签页：
   (1) 可信评估：综合可信分（0–100 圆环）+ 高/中/低可信等级徽章 + 加权
       贡献分解 + 六维雷达图（真实性、安全性、公平性、鲁棒性、隐私保护、
       伦理合规），每个维度可展开查看权重、评估方法、证据与检查明细。
   (2) 法条溯源：列出 RAG 检索到的相关法条，含法律名称、条号、相关度
       百分比与时效标签；已废止法条标红并提示「参见新法」，回答气泡同时
       附加「含已废止法条」警告角标。
   (3) 引用核验：对模型显式引用逐条对照法条原文并给出裁决与吻合度；对
       隐性论断做 NLI 支撑判断；上传文档场景还有「文档引文核验」，逐字
       比对防止编造条款；可显示自动修正次数。
   (4) 工具轨迹：智能体场景下记录每轮工具调用的工具名、参数、结果摘要
       与耗时，调用过程全程可审计；普通问题不显示该 Tab。

三、多模态上传与文档审查
--------------------------------------------------------------------------------
系统支持在提问时附带多种格式的文件，实现「文档 + 问题」的多模态法律分析。

1. 支持范围
   · 支持格式：txt、md、docx、pdf 及 jpg/png/bmp/tiff/webp 图片（图片自动
     走 OCR 文字识别）；最多 5 个附件，单文件不超过 10MB。
   · 纯文档提问：仅上传文档不输入文字时，系统自动以「请分析以上上传的
     文档内容…」发起提问。
   · 未上传文档直接要求审查时，系统引导先上传合同文件，不空跑模型调用。

2. 合同审查
   上传合同类文档并附带审查信号提问（如「这份合同有什么风险条款？」），
   系统进入合同审查任务：输出【合同风险清单】（逐条风险 + 法律依据）与
   【总体评价】；回答中引用文档原文之处经「文档引文核验」逐字比对，
   确保不编造条款。

3. 图片 OCR 与通用文档分析
   · 图片审查：上传借条图片等文件后，系统自动 OCR 识别文字，回答可引用
     图中识别出的金额、利率、违约金等内容进行法律风险分析。
   · 非法律文档：上传非法律文档且提问不含法律关键词时，走文档分析模式——
     客观总结文档要点，不套三段式、不罗列无关法条，结尾引导法律咨询。

四、隐私保护
--------------------------------------------------------------------------------
系统在输入端部署了三类守卫机制，前后端双重生效，从源头保护用户隐私并
拦截违法请求。

(1) 滥用拒答：对伪造合同、销毁证据、酒驾逃避处罚、贿赂、伪证、洗钱等
    违法请求直接「安全拦截」，展示拒答文案，不调用大模型、不参与可信评估。
(2) 敏感信息脱敏：提问中的身份证号、银行卡号自动脱敏（如
    110101********1234）并弹出提示，回答聚焦法律问题本身而非证件信息。
(3) 一般隐私确认：提问包含手机号、详细地址等隐私内容时弹出隐私确认框，
    用户「确认发送」后才会继续，可选择取消放弃发送。

此外，设置面板「隐私与安全」区提供敏感信息主动提示开关；账号体系支持
修改密码（旧密码校验 + 吊销其他设备）；六维可信评估中专门设有「隐私保护」
维度，对回答是否泄露或诱导泄露隐私进行量化评分。

--------------------------------------------------------------------------------
五、意图路由
--------------------------------------------------------------------------------
系统对每条用户输入自动进行意图识别，区分四类意图并差异化处理，避免资源
浪费、保证法律问题获得完整分析：

(1) 寒暄：「你好」「谢谢」等简短问候，友好回应并介绍法律服务范围；不启用
    RAG 检索、无可信分角标、右侧详情面板不展示评估。
(2) 通用非法律：「今天天气怎么样」「帮我写首诗」等，说明无法回答并引导
    提出法律问题，不启动法条分析。
(3) 法律咨询：进入完整流水线——RAG 法条检索、生成三段式回答、三级引用
    核验与六维可信评估。
(4) 文档分析：携带文档的输入按文档内容进行针对性分析（合同审查 / 要点
    总结等）。

意图路由由关键词与语义共同驱动：例如「民间借贷利率的合法上限是多少？」
会正确判定为法律咨询；涉及已废止法律（婚姻法、收养法、物权法、专利法等）
的时效问题则自动进入时效查询，由注册表驱动给出确定性结论，而非硬编码名单。

六、多模型选择与 API 接口配置
--------------------------------------------------------------------------------
1. 模型选择器
   输入区右下角提供两级模型选择：
   · 离线调用：本地 Qwen2.5-7B 引擎，需 CUDA GPU 与本地模型权重；未就绪
     时自动置灰并悬停显示原因。
   · API 调用：可选 Auto（跟随设置面板的全局默认模型，默认 qwen3.7-plus）
     或 7 款百炼托管模型——qwen3.7-plus、qwen-turbo、qwen3.7-max、
     deepseek-v4-flash-0731、deepseek-v4-pro、kimi-k2.6、glm-5.2。

   所选模型按请求透传，多用户并发互不串模型；自一致性核验自动沿用所选
   模型。回答气泡左下角显示模型角标（含品牌 logo），选 Auto 时显示星光
   标识、悬停可见实际使用的模型名。

2. API 接口配置
   · 每账号可在设置面板「模型与推理」中自配百炼 API Key（形如 sk-*******）；
     未配置时自动回退服务端 .env 中的默认 Key。
   · 无效 Key 保存后提问会收到中文错误提示（API 鉴权失败类文案），改回
     空值即恢复默认 Key。
   · 设置面板还可开启深度思考模式（适合复杂法律推理，响应更慢），并调整
     自一致性采样次数、NLI 引用核验、引用展示风格等推理选项。
