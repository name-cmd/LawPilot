律策智枢 LawPilot 平台技术说明文档

一、项目概述
律策智枢 LawPilot是一个面向中文法律场景的可信智能问答平台，采用 RAG（检索增强生成）架构，
将法律条文检索、大语言模型生成、引用核验与可信评估整合为统一问答流水线。

二、系统架构
后端采用 FastAPI 提供 REST 与 SSE 流式接口，前端为 Vue 3 + TypeScript 单页应用。
核心模块包括：意图路由、查询重写、向量检索、三级引用核验、六维可信评估、
智能体任务调度与工具调用引擎。

三、技术栈
- 编程语言：Python 3.x / TypeScript
- 大语言模型：阿里云百炼 API（多模型注册表，7 款可选）
- 向量检索：bge-base-zh-v1.5 嵌入 + ChromaDB
- 前端框架：Vue 3 + Vite + Naive UI + ECharts

四、部署方式
1. 安装 Python 依赖：pip install -r requirements.txt
2. 配置 DASHSCOPE_API_KEY 至根目录 .env
3. 构建知识库：python scripts/build_knowledge_base.py
4. 启动服务：python scripts/run_server.py
5. 浏览器访问 http://localhost:6006
