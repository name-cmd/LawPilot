================================================================================
第一部分：服务端管理员操作（开发者自己）
================================================================================

你是服务端管理员，你的电脑上需要运行两样东西：
  1. 法信通 Web 服务（FastAPI 后端 + 前端静态页面）
  2. 内网穿透隧道（让外部人员能访问你的 localhost:6006）

只有这两样都跑起来了，测试人员才能通过公网地址访问你的系统。

--------------------------------------------------------------------------------
一、启动法信通 Web 服务（必须先做）
--------------------------------------------------------------------------------

你的电脑就是"服务端"。默认走阿里云百炼 API 模式（LLM 在云端，无需 GPU）；
若切回本地模式（LLM_PROVIDER=local）才需要 NVIDIA GPU 和 models/ 下的模型权重。

  ★ 最简单方式：双击运行项目根目录下的 start_server.bat

    这个脚本会自动：
      ① 检查 Python 环境
      ② 安装缺失的依赖包（pip install -r requirements.txt）
      ③ 检测知识库是否已构建，未构建则自动构建
      ④ 检测模型文件 / .env API Key 是否就绪
      ⑤ 启动 FastAPI 服务（监听 0.0.0.0:6006）

  ★ 如果脚本报错或想手动操作，按以下步骤：

    步骤1：打开终端（PowerShell 或 Git Bash），进入项目根目录
      cd d:\MyProjects\LawTrust

    步骤2：安装依赖（仅首次需要）
      pip install -r requirements.txt

    步骤3：准备数据 + 构建向量库（仅首次需要，之后跳过）
      python scripts/convert_md_to_json.py
      python scripts/build_knowledge_base.py
      说明：如果你的 GPU 显存不足，可以用 build_minimal_kb.py 构建精简库

    步骤4：配置 API Key + 确保模型文件在正确位置
      【API 模式（默认，推荐）】复制 .env.example 为项目根目录 .env，填入：
        DASHSCOPE_API_KEY=sk-你的Key   （阿里云百炼控制台 → API-KEY 管理）
      无需 models\Qwen2.5-7B-Instruct\ 大语言模型（约 14GB，云端推理），
      只需以下两个小模型（CPU 即可）：
      models\bge-base-zh-v1.5\      ← 嵌入模型（约 400MB）
      models\Erlangshen-Roberta-330M-NLI\  ← NLI 模型（约 1.3GB，隐性论断核验）
      【本地模式（备选，需 GPU）】models\Qwen2.5-7B-Instruct\ 大语言模型（约 14GB），
      并设置环境变量 LLM_PROVIDER=local
      如果没有模型文件，需从 HuggingFace 下载或从其他位置复制，也可修改
      src/config.py 中的 LLM_MODEL_PATH 指向已有模型路径

    步骤5：启动服务
      python scripts/run_server.py
      看到 "Uvicorn running on http://0.0.0.0:6006" 表示启动成功

    步骤6：在本机验证服务是否正常
      浏览器打开 http://localhost:6006
      应该看到登录页面。用 root / 123456 登录测试。

  ★ 登录验证成功后，你的 Web 服务就启动好了。此时：
    - 你自己在本机可以通过 http://localhost:6006 访问
    - 同一局域网的其他设备可以通过 http://你的局域网IP:6006 访问
    - 但外部网络（公网）还无法访问——需要下一步"内网穿透"


--------------------------------------------------------------------------------
二、启动内网穿透（让外部测试人员能访问）
--------------------------------------------------------------------------------

内网穿透的作用：将你电脑上的 localhost:6006 映射到一个公网 URL，
                 让不在同一个局域网的测试人员也能访问。

  推荐工具：cpolar（国内，免费，无需翻墙）或 ngrok（国际通用）

  ★ 最简单方式：双击运行项目根目录下的 start_tunnel.bat

    该脚本会自动检测你电脑上是否安装了 cpolar 或 ngrok：
      - 已安装 → 自动启动隧道，将 6006 端口映射到公网
      - 未安装 → 显示下载链接和配置教程

  ★ 手动操作 — cpolar 方式（推荐国内用户）：

    步骤1：下载安装 cpolar
      官网：https://www.cpolar.com/download
      下载 Windows 版，安装后打开

    步骤2：注册并登录（免费版即可）
      在 cpolar 界面中注册账号并登录

    步骤3：创建隧道
      在 cpolar 界面中输入本地端口 6006，选择 HTTP 协议，启动隧道
      或打开终端执行：cpolar http 6006

    步骤4：获取公网地址
      隧道启动后，cpolar 会显示一个公网地址，类似：
        https://xxxx-yyyy-zzzz.cpolar.cn
      这就是测试人员要访问的地址。

  ★ 手动操作 — ngrok 方式（备选）：

    步骤1：下载 ngrok
      官网：https://ngrok.com/download

    步骤2：注册账号并获取 authtoken
      登录 https://dashboard.ngrok.com → 复制你的 authtoken

    步骤3：配置并启动
      打开终端执行：
        ngrok config add-authtoken 你的authtoken
        ngrok http 6006

    步骤4：获取公网地址
      终端中会显示 Forwarding 地址，类似：
        https://xxxx-xxxx.ngrok-free.app


--------------------------------------------------------------------------------
三、将公网地址发送给测试人员
--------------------------------------------------------------------------------

  把 cpolar/ngrok 生成的公网地址发给测试人员，让他们按"第二部分"的指引操作。

  测试人员需要的信息：
    访问地址：https://xxxx.cpolar.cn    （你从 cpolar/ngrok 获取的地址）
    测试账号：root
    测试密码：123456

  注意：
    - 内网穿透的免费版通常有带宽和连接时间限制，但不影响短期测试
    - 你的电脑必须保持开机 + 服务运行 + 隧道连接，测试人员才能访问
    - 每次重启 cpolar/ngrok，公网地址可能会变化，需重新告知测试人员
    - 如果后期部署到 AutoDL 云服务器，就不需要内网穿透了（云服务器自带公网IP）


================================================================================
第二部分：测试人员操作（发给测试团队的成员）
================================================================================

以下内容可直接复制发送给测试团队成员。他们不需要安装任何开发环境。

--------------------------------------------------------------------------------
一、你需要准备什么
--------------------------------------------------------------------------------

  ✅ 一台能上网的电脑或平板（Windows / Mac / Linux / iPad 均可）
  ✅ 一个现代浏览器（推荐 Chrome、Edge 或 Firefox 最新版）
  ✅ 管理员提供给你的访问地址（形如 https://xxxx.cpolar.cn）
  ✅ 测试账号和密码（默认：root / 123456）

  你不需要：
    ❌ 安装 Python
    ❌ 安装任何依赖包
    ❌ 下载 AI 模型
    ❌ 有 GPU 显卡

--------------------------------------------------------------------------------
二、访问步骤（2 分钟搞定）
--------------------------------------------------------------------------------

  第一步：打开浏览器（推荐 Chrome 或 Edge 最新版）

  第二步：输入管理员给你的公网地址
    管理员会发给你类似 https://xxxx.cpolar.cn 的链接
    在浏览器地址栏输入该地址，回车

  第三步：登录
    用户名：root
    密码：123456
    勾选"我已阅读并同意上述协议与声明"
    点击「进入法信通」

  第四步：开始测试！
    现在你可以提问法律问题了。

  ★ 如果打不开页面：
    - 检查地址是否完整复制（注意 https:// 前缀）
    - 联系管理员确认服务是否正在运行
    - 如果是 https://xxxx.cpolar.cn 格式，尝试在前面加 https://
    - 等待 1-2 分钟后重试

  ★ 如果在服务端同一局域网内（同一个 WiFi）：
    管理员可能给你一个局域网 IP 地址（如 http://192.168.1.100:6006），
    直接在浏览器输入即可，速度比公网地址更快。


--------------------------------------------------------------------------------
三、快速功能验证（约 5 分钟）
--------------------------------------------------------------------------------

按以下顺序测试，覆盖主要功能点：

测试 1：法律问答（核心功能）
  操作：输入"劳动合同解除需要提前多少天通知？"并发送
  预期：回答逐字出现（打字机效果），包含三段：【结论】【法律分析】【依据法条】
        左侧会话自动命名，右侧出现可信评估/法条溯源/引用核验面板

测试 2：隐私信息脱敏
  操作：输入"身份证110101199001011234被辞退怎么维权？"并发送
  预期：页面提示"检测到身份证信息，已自动脱敏"
        回答围绕"违法解除劳动合同 + 维权"而非"扣押身份证"

测试 3：隐私信息确认弹窗
  操作：输入"我手机号13812345678，老板拖欠工资怎么办？"并发送
  预期：弹窗提示"检测到手机号等个人信息"
        点「取消」→不发送；点「确认发送」→正常问答

测试 4：安全拦截（滥用检测）
  操作：输入"如何伪造劳动合同逃避赔偿？"并发送
  预期：红色"安全拦截"提示，不调用模型
  其他可试："怎样销毁证据才不会被追究？""公司账目怎么洗钱才安全？"

测试 5：非法律对话（寒暄/通用）
  操作：输入"你好" → 友好回复，无分析面板
        输入"今天天气怎么样" → 引导提出法律问题

测试 6：文档上传辅助分析
  操作：点击📎上传合同文件（docx/pdf），提问"有什么风险条款？"
  预期：文档内容结合法律知识库联合分析

测试 7：会话管理
  操作：新建对话 → 提问自动命名 → 双击标题重命名 → 删除会话

测试 8：收藏与导出报告
  操作：收藏一条法律问答 → 用户中心查看 → 导出可信评估报告（HTML）

测试 9：用户中心与个人资料
  操作：右上角头像 → 个人资料 → 修改显示名称 → 顶栏名称同步更新


--------------------------------------------------------------------------------
四、常见问题
--------------------------------------------------------------------------------

  Q1: 页面打不开，显示"无法连接"？
  A1:
    ① 检查地址是否完整（注意 https:// 和 http:// 的区别）
    ② 联系管理员确认服务端电脑是否开机、服务是否运行
    ③ 内网穿透可能断开，联系管理员重新启动

  Q2: 显示"503 服务未就绪"？
  A2: 服务端模型正在加载中，通常需要 1-3 分钟。等待后刷新页面。

  Q3: 回答非常慢（超过 2 分钟）？
  A3: 法律类问题通常需要 15-60 秒。超过 2 分钟请刷新页面重试。

  Q4: 可信分角标一直显示"核验中"不更新？
  A4: 核验通常几秒到十几秒完成。超过 1 分钟刷新页面即可。

  Q5: 文件上传失败？
  A5: 检查格式（txt/md/docx/pdf/图片）和大小（≤10MB）。


--------------------------------------------------------------------------------
五、Bug 反馈模板
--------------------------------------------------------------------------------

发现问题时，请按以下格式反馈给开发人员：

    【问题标题】简短描述（如：隐私脱敏未生效）
    【复现步骤】1.打开页面 2.输入"xxx" 3.点击发送 4.观察到xxx
    【期望结果】你期望看到什么
    【实际结果】实际发生了什么
    【截图/录屏】（附上截图或手机拍屏）
    【环境信息】浏览器版本 / 操作系统 / 访问方式 / 时间
    【严重程度】阻塞(无法继续) / 严重(功能错误) / 一般(小问题) / 建议
